第三人

THE THIRD MAN · 1934–1963

你是金·菲尔比，英国军情六处的明日之星，也是苏联最成功的间谍之一。替他做五个决定。1945 年，路分成三条：照历史走；提前投奔苏联；或者同时出卖两边，让谁都不知道你真正属于谁。

这个小样包含什么

一个"替历史人物做决定"的互动剧情。五章对应金·菲尔比一生中五个真实事件，每次选择后都会弹出解密档案，告诉你历史上他实际怎么做。档案里的配图是用代码画的老照片风格场景（标注了"画面重现"），拿到授权的历史照片后可以直接替换。

章节事件史实要点
1934伦敦 · 被招募在摄政公园与苏联情报官阿诺德·多伊奇见面，同意为苏联工作
1945伊斯坦布尔 · 沃尔科夫苏联叛逃者要揭发英国反间谍部门的内鬼，菲尔比接手并拖延，沃尔科夫失踪
1951华盛顿 · 荷马得知"荷马"就是麦克林，通过伯吉斯示警，两人出逃苏联
1955伦敦 · 记者会被指为"第三人"，在母亲的公寓里召开记者会公开否认
1963贝鲁特 · 摊牌军情六处的老友埃利奥特当面摊牌，菲尔比随后出逃莫斯科

玩法：一共 15 个结局。每个决定有三个选项（1945 和 1963 年的史实线有四个）。偏离的选项不会马上结束，而是先出现后果，再给你一次补救的机会：补救成功就绕回原来的路线，补救失败就走向别的结局。新路线里也会穿插真实的历史档案，比如柏林隧道和格利尼克桥。右上角的怀疑值会随你的选择变化，并影响最后一章的对话。每一章有自己的配乐，全部由浏览器实时合成。角色说话有配音：页面会挑你设备上最自然的中文男声来读，每个角色的声音和语速不同；用 Windows 上的 Edge 浏览器效果最好。以后把真人录音按台词编号放进来，就会自动换成录音。人物以剪影出现，场景和人物都可以替换成真实照片或插画。

配音

角色台词会配音，只用成熟的中文男声。有录音文件时播放录音；没有时用你设备上的中文男声朗读，找不到男声就不配音。

设备怎样获得中文男声
Windows · Edge自带微软自然语音（云扬、云健等），效果最好，不用设置
Windows · Chrome在 Windows 设置里添加中文语音包，会多出男声「康康」；声音较机械，建议换用 Edge
Mac / iPhone在「辅助功能 → 朗读内容 → 声音 → 中文」里下载一个男声，下载后刷新本页
安卓浏览器通常只提供女声，建议用录音版本
